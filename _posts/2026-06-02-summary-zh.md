## [Red Hat npm 包遭 Shai-Hulud Miasma 后门攻击](https://arstechnica.com/security/2026/06/dozens-of-red-hat-packages-backdoored-through-its-offical-npm-channel/) ⭐️ 9.0/10

安全公司 Aikido 和 OX Security 发现，Red Hat 官方 @redhat-cloud-services 命名空间中的 30 多个 npm 包被植入了名为 Miasma 的 Shai-Hulud 新变种后门。攻击窃取了开发者凭据、云密钥、SSH 密钥和 CI/CD Token，恶意版本每周下载量约 11.7 万次。 此次供应链攻击针对 Red Hat 官方渠道，可能影响数千家依赖这些包的组织。该事件凸显了 Shai-Hulud 恶意软件日益增长的威胁，此前 Bitwarden、SAP、Mistral、TanStack、OpenAI 和 GitHub 等项目已遭攻击。 攻击者入侵了一名 Red Hat 员工的 GitHub 账户，推送了添加 GitHub Actions 工作流的恶意提交，从而发布带后门的版本。4.2 MB 的恶意载荷窃取包括 AWS、Google Cloud、Azure 凭据、HashiCorp Vault Token、Kubernetes 服务账户 Token、npm 和 PyPI 发布 Token、SSH 密钥、Docker 凭据、GPG 密钥以及 .env 文件在内的机密信息。

rss · Ars Technica · Jun 1, 19:49

**背景**: Shai-Hulud 是一种蠕虫式恶意软件，自 2025 年 9 月起通过 npm 包传播，已感染超过 500 个包和数千个 GitHub 仓库。与早期版本（如 Mini Shai-Hulud）相比，Miasma 变种增加了混淆、多阶段载荷投递和更强的数据窃取能力。Red Hat 已从 npm 移除受影响包，并表示事件限于内部开发工具，未通过 console.redhat.com 影响客户。

## [类生化过程可能是地质的自然特征](https://www.quantamagazine.org/the-dirt-that-refused-to-die-20260601/) ⭐️ 8.0/10

新研究表明，以前被认为生命独有的化学反应（如涉及有机化合物和能量梯度的反应）实际上可能是地质过程的固有特征，模糊了生命与非生命之间的界限。 这一发现挑战了关于生命起源的基本假设，并对天体生物学具有重要意义，因为它表明类生化化学过程可能在没有生命的其他行星上发生，从而指导地外生命的搜寻。 该研究强调，深海热液喷口等地热过程可以产生稳定的能量梯度，驱动有机化合物的合成，模拟生化途径，而无需生命参与。

hackernews · speckx · Jun 1, 15:11 · [社区讨论](https://news.ycombinator.com/item?id=48357905)

**背景**: 生命起源（abiogenesis）是生命从非生命物质（如简单有机化合物）自然产生的过程。主流假说认为，生命起源于早期地球上的一系列日益复杂的化学反应。这项研究进一步证明，许多此类反应可以在纯地质环境中发生，支持了生命化学源于地质学的观点。
